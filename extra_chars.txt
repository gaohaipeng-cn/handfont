# ===================================================================
# HandFont 补充字表 —— GB2312 之外的常用字
#
# 用途：GB2312 只收了 6763 个汉字，很多人名用字（珺、玥、瑀、喆、赟…）
#       不在其中。这里的字会显示在软件的「补充字」选项卡里，单独书写。
#
# 自定义方法（任意文本编辑器打开即可，注意存成 UTF-8）：
#   1. "#" 开头的整行是注释，不会收进软件，可以随便写说明；
#   2. 其他行里出现的每个汉字都会被收录，一行写多少个都行；
#   3. 重复的字自动去重；已经在 GB2312 里的字会被自动跳过（不会重复出现）；
#   4. 改完保存，重启软件生效。
#
# 例：想加"琋"，在任意一行末尾加上它即可。
# ===================================================================
