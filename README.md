# HandFont 手写字体生成器

把自己的手写笔迹变成一款可用的 TTF 字体：在屏幕的米字格里用鼠标或数位笔逐字书写，程序把手写笔画转换成字形轮廓，导出成标准 TTF，安装后在 Word、WPS等软件里就能用自己的手写字体。

## 软件介绍

- **字符覆盖**：GB2312 全部汉字 + 半角 ASCII + 补充字（GB2312 未能覆盖的常用字，人名用字为主）。支持按字频排序，也按区位表顺序浏览。
- **补充字可自定义**：珺、玥、瑀、喆、赟 这类 GB2312 没收的人名常用字单独一张选项卡；想加字就编辑 `extra_chars.txt`（`#` 开头是注释），重启生效。源码运行时该文件在项目根目录，打包版在 `_internal` 目录里。
- **两种练习格**：汉字用米字格（居中/对称参考），拉丁字母用四线三格（基线、x 高线、字宽虚线），字母自动压基线，降部字母（g p y q j）有专属空间。
- **描红底字**：格子里淡显当前字的楷体字形，照着笔画写；底字只作参考，不会进导出的字体。
- **2×2 四格练习**：同一个字可以写四遍，哪格满意就激活哪格保存（只有当前活动格会被保存）。
- **压感笔支持**：数位笔的压感实时影响笔画粗细；不用数位板，鼠标也能写（无压感、等线宽）。
- **所见即所得**：画布预览与导出 TTF 共用同一套笔画粗细公式，预览什么样，装到系统里就是什么样。
- **精细调整**：笔画粗细滑块；方向键微调整个字形在格子里的位置（Shift 大步 / Ctrl 细调 / Ctrl+0 复位）；拉丁字符可拖字宽虚线自定义宽度。
- **SQLite 单字存储**：每写完一个字立即落盘（毫秒级），不怕中途断电退出。
- **导出双模式**：
  - **精简模式**（默认）：只打包写过的字，文件小、纯手写；
  - **完整模式**：以系统楷体为底，只替换写过的字——没写的字用楷体兜底，装上即可直接日常使用。
- **Word 加粗兼容**：导出前对每字笔画轮廓做布尔并集，消除重叠轮廓，Word 里加粗时墨迹均匀、不会出现半截粗。

## 依赖

- **操作系统**：**Windows 10 及以上**（不支持 Win7：Python 3.12 与 Qt6 均要求新系统。需要系统里的楷体字体做度量模板：华文楷体 `STKAITI.TTF` 或简体楷体 `simkai.ttf`，系统一般自带）。
- **Python** 3.8 及以上。推荐 64 位 Python 3.12。
- **Python 包**：

  ```
  pip install PySide6 fontTools
  ```

  说明：代码同时兼容 PySide2（Qt5）——32 位 Python 或装不了 PySide6 的环境可用
  `pip install PySide2==5.15.2.1 fontTools`，程序启动时自动识别，但**官方只提供 Win10+ 64 位发布包**，其余环境需自行从源码运行。

## 使用方法

1. **启动**：在本目录执行 `python handfont.py`。首次运行会在程序旁创建空的工程库 `handfont_project.db`。

2. **选字**：左侧选项卡切换 GB2312 / ASCII /补充字 字符卡片，点击任意字（悬停可看 Unicode 码位和 GB2312 区位）；可勾选按字频排序，常用字排在前面。

3. **书写**：在右侧格子里用鼠标或数位笔书写。可在 2×2 四格里多写几遍，单击选中最满意的一格。
   - 「撤销」去掉最后一笔，「清除」清空当前格；
   - 「淡显底字」开关描红参考；
   - 笔画太细/太粗拖「笔画粗细」滑块。

4. **保存**：点「保存」或按 `Ctrl+S`，当前格的字写入工程库，并自动跳到下一个字。
   - 在空白格上点保存 = 把这个字恢复为未写状态（会弹确认）。

5. **导出**：点「导出TTF」，选好文件名和模式（精简/完整），生成 `.ttf` 文件。右键该文件选「安装」，或复制到 `C:\Windows\Fonts`，之后在 Word、WPS 等软件的字体列表里选它即可。

6. **数据备份**：您的全部笔迹都在 `handfont_project.db` 里，备份 = 复制这个文件。

## 打包方法

打包成免安装的 exe 用 `build.bat`（64 位）：

```
build.bat            :: 文件夹版（onedir）: dist\HandFont\HandFont.exe，启动快（默认）
build.bat onefile    :: 单文件版: dist\HandFont.exe，方便分发，启动稍慢
```

- **全自动自检**：脚本会自动定位 Python（找不到时通过 winget 安装）、创建隔离的构建虚拟环境、安装 PyInstaller（≥6.10）和依赖，环境损坏会自动重建——一台新电脑上直接双击即可。
- **自动瘦身**：打包完成后 `slim.py` 自动裁剪本项目用不到的 Qt 模块，产物从约 128MB 降到约 65MB。
- **不带用户数据**：产物不含工程库，首次运行在 exe 旁自动创建空 `handfont_project.db`，互不干扰。

## 目录结构

```
handfont.py        主程序（单文件，约 2000 行）
slim.py            打包产物裁剪工具（build.bat 自动调用）
build.bat          64 位打包脚本
char_freq.txt      汉字字频表（排序用）
extra_chars.txt    补充字表：GB2312 之外的常用字，可自行增减（打包后位于 _internal 目录）
app.ico            程序图标
```
